# Checkly

重複排程、月曆與近期任務合一的待辦事項 PWA，手機與電腦共用同一份資料。

**線上版本**：<https://jeremyl861225.github.io/checkly/>（改名前的舊版仍在 <https://jeremyl861225.github.io/todo-app/>，兩邊共用同一個 Supabase 專案與帳號）

![screenshot](icon-192.png)

**兩種外觀主題**（右上「⋮」→「主題」，即時切換、不必重新載入；記在這台裝置）：
- **打字機**（預設）：扁平、等寬字（JetBrains Mono）、`[ ]`／`[x]` 勾選框、反白選取，
  標頭是跳字的英文頁名＋中文，冷啟動有亂碼跳字的開場（選單可關）；
  月曆不靠顏色、靠**符號**區分種類（見下），右上的同步標籤是電傳打字機式的狀態碼（`[OK] 已同步`、`[UP] 待上傳 2`、`[--] 離線`…）
- **糖果紙**：改名前 todo-app 的原本樣子（卡片、圓角、SVG 勾勾），標頭是原本的 icon＋Checkly

兩種主題是同一份畫面與同一份資料，只換樣式；雲端（Supabase 專案、資料表、欄位）完全沒變。

## 功能

**頁面一 — 重複排程**
- 依「每日 / 每週 / 每月 / 自訂」分組列出；打字機主題每筆的最右側有「下次 明天／3 天後…」，前面接一串點線引導
- 每筆都有**起始日**（必填，預設當天）與**結束日**（選填，留空表示持續進行）
- 自訂＝每 N 天／每 N 週（週幾）／每 N 個月（幾號），從起始日起算
- 每月可選「幾號」或「第幾個星期幾」（第一～第四個／最後一個）；
  選幾號時當月沒有那天會自動落在該月最後一天
- 新增、編輯、刪除；點卡片看完整內容
- 每筆包含標題、時間、敘述、相關連結（自訂名稱＋網址，可多筆）、類別
- 已過結束日的排程在清單上會淡化並標「已結束」

**頁面二 — 月曆**
- 與頁面一即時同步，桌機在格子內顯示事項、手機顯示記號
- **近期任務（有截止日的）也依截止日出現在月曆**，勾選與近期任務、未完成兩頁同步
- 勾選完成，**只影響被勾的那一天**（任務例外：任務只有一次，勾了就是完成）
- **記號（打字機主題，完全不用顏色）**：`•` 重複排程、`○` 單一行程、`×` 近期任務、`▮` 重大事件（取代原本的種類記號）、
  `──` 多日行程（重大的加粗）；**已完成的記號淡到只剩約 16%**，一眼分得出未完成（圖例不另外註明）。
  糖果紙主題仍用類別色（圓點／菱形／小方塊／星）
- 可新增「單一行程」，**支援跨多日活動**（例如 8/12–8/14 的研討會）
- **多日行程以連續橫桿橫跨那幾天**，跨週自動切段、重疊自動分層
- 糖果紙主題的樣式：多日行程是橫桿，單日行程是圓角描邊色塊／菱形點，
  重複排程是灰底左側色條／圓點，任務是描邊方塊
- 僅單一行程能在此頁編輯／刪除；重複排程只能勾完成，內容要回頁面一修改

**頁面三 — 近期任務**
- 一次性的任務（不是重複排程）；**有截止日的會依截止日出現在月曆**（沒有截止日的不會）
- 依截止日自動分成「已逾期 / 今天到期 / 一週內 / 之後 / 未定截止日」
- 每張卡片顯示名稱、截止日、類別與完成度
- 可拆成**子任務**：完成度用一排**小方塊**呈現（一個子任務一格，完成就亮，格與格之間留縫、全滿也不會黏成一條），
  標題下並以小灰字顯示**第一個還沒完成的子任務**；
  編輯畫面可**按住握把拖曳調整子任務順序**（觸控與滑鼠皆可，鍵盤用 ↑ ↓）
- 點卡片進入詳細內容：逐項勾選子任務、開啟相關連結、編輯、刪除

**頁面四 — 未完成**
- 把「還沒勾完成」的東西攤成一份條列：**月曆上沒勾的重複排程與單一行程＋近期任務**，
  依「已逾期 / 今天 / 明天 / 一週內 / 之後 / 未定截止日」分組，同樣能用類別與「★ 重大」篩選
- 這一頁不存任何資料，每次從同一批資料現算：在月曆或近期任務勾完成，這裡**自動少一筆**；在這裡勾，月曆與近期任務也跟著變
- **過去**：重複排程與單一行程從起始日到昨天「所有沒勾的」全部列出，不設回溯上限（每一次各一筆；多日行程逐日各一筆）
- **今天起**：重複排程沒有盡頭，每一條只列接下來（`PEND_AHEAD` = 7 天內）第一次沒勾的，每天都有的排程才不會一天一筆洗版；
  單一行程不受天數限制，列出第一個沒勾的那天
- **近期任務**：全部（逾期再久也在），沒有截止日的排最後
- 清單可能很長，畫面外的卡片用 `content-visibility` 跳過版面計算（5000 筆時切到這頁約 0.5 秒）

### 排程與行程的子事項
- 重複排程與單一行程也能拆子事項，用同一套編輯介面（拖曳排序、勾選）
- 勾選**逐次計算**：重複排程今天勾完，下一次出現時重新開始；
  當日清單與詳細內容都會顯示 `n/m` 的完成度
- 勾選完成會**記下完成日期**，之後在清單再留 **2 天**，滿兩天才移入「已完成」；
  取消勾選再勾一次，完成日期會更新、兩天重新算起
- 右上角「已完成」可翻到歸檔頁，依完成月份分組；在那裡取消勾選就會回到近期任務

**iPhone 桌面小工具 / 鎖定畫面桌布**
- 桌面放一個**大型小工具**：上方本週七天（每天一排彩色事項條）、
  下方今天的事項卡片；**點某一天會開啟 App 跳到那天**
- 鎖定畫面的小工具區只有時鐘下面那一小條，放不下整週——
  想在鎖定畫面看到週曆，是把同一個版面**畫進桌布圖片**，由捷徑定時換上（只能看、不能點）
- 需要 App Store 上免費的 **Scriptable**；設定在選單的「桌面小工具」，
  會產生一個唯讀網址與四行貼上用的程式碼

**其他**
- **日期寫法全 App 統一**：`11 月 10 日週六`（清單、標籤、月曆標題、詳細內容、對話框都一樣，程式裡的 `fmtDW()`）；
  只有重複排程節奏條旁的「下次」那一欄太窄，遠的日期改寫成「3 週後」
- **重大事件標記**：重複排程、單一行程與任務都可標記，清單置頂加標記（打字機主題全站都是 `▮`，糖果紙是星號），
  並可用「★ 重大」單獨篩選
- Email + 密碼註冊／登入，登入狀態會記住；可更改密碼，忘記密碼可寄重設信
- 類別可自訂（預設「工作」「私人」）
- 匯入／匯出備份 JSON

## 資料保存

1. 所有變更立即寫入 Supabase（雲端）
2. 同時在瀏覽器留一份快取，開啟時先顯示快取再與雲端對時 → 離線或連線失敗**不會變空白**
3. 離線時的操作進入待上傳佇列，右上角顯示「待上傳 N」，恢復連線自動補送
4. 選單可手動匯出 JSON 備份

## 技術

- 單一 `index.html`，無建置流程
- [Supabase](https://supabase.com) 提供 Email/密碼登入與 Postgres；Row Level Security 確保每個帳號只讀得到自己的資料
- supabase-js 放在 `vendor/` 而非 CDN，離線與擋外部網域的環境都開得起來
- iPhone 小工具走「App 算好、推唯讀快照」：重複排程的展開規則只留在 App，
  伺服器不重寫一份，所以不會有兩套規則各自漂移。快照存在 `widget_feeds`，
  小工具帶 token 打 Edge Function `widget` 讀它。腳本與版面預覽在 [`widget/`](widget/)
- `sw.js` 快取 App 外殼（先給快取所以秒開，背景更新外殼，下次開啟就是新版），
  字型、vendor、圖示依內容雜湊分代、整批換新。快取名稱一律 `checkly-` 前綴、清理時只刪自己的，
  且只處理 `/checkly/` 底下的同源 GET，不會影響同網域其他 PWA；Supabase 的 API 永遠走網路，不進快取。
  前綴刻意跟舊版的 `todo-app-` 分開：兩個 App 在同一個網域，同名前綴的話雙方清理「自己的舊快取」時會刪到對方
- **改了任何 precache 檔（字型、vendor、圖示、manifest）或 `sw.js` 的 PRECACHE 之後**，跑
  `node tools/gen-sw-precache.mjs` 重算 `sw.js` 的 BUILD 與逐檔雜湊（沒有建置流程，Node 18 以上即可）；
  部署前跑 `node tools/gen-sw-precache.mjs --check`：雜湊過期、或 `index.html`／manifest 引用了不在 PRECACHE 的本機檔都會擋下
- 動態全部是原生 JS＋CSS／Web Animations，沒有框架；字型是本機的 JetBrains Mono 子集（`fonts/`，OFL），
  亂碼跳字、ASCII 粒子、轉圈字元都只能用字型裡有的字元：`node tools/check-glyphs.mjs` 檢查跳字的字元表，
  `node tools/check-glyphs.mjs "▖▘▝▗"` 檢查任意字串，`--ranges` 列出字型有哪些符號（`✦` 不在字型裡）
- 本機資料一律存在 `checkly.*` 鍵（快取、上傳佇列、目前分頁、明暗、外觀主題 `checkly.skin`、開場開關、試用資料），
  **絕不寫、不刪舊版的 `todo.*`**：舊版還在同一個網域（iPhone 主畫面與小工具仍指向它），
  而且它每次都把自己記憶體裡的整份佇列寫回 `todo.queue.<uid>`，共用鍵會抹掉 Checkly 還沒送出的變更。
  某個帳號第一次在這台瀏覽器開 Checkly 時，會從舊版**讀一次**快取與還沒送出的變更（見 `index.html` 的 `importLegacyOnce`）；
  登入（supabase-js 的 `sb-*-auth-token`）兩邊共用，不必重新登入

## 自行部署

見 [SETUP.md](SETUP.md)：建立 Supabase 專案 → 執行 [schema.sql](schema.sql) → 填入 `index.html` 最上方的 `CONFIG` → 放上 GitHub Pages。

不想設定也可以先加 `?demo=1` 試用，資料只存在本機瀏覽器。
